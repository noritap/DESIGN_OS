# DESIGN_OS

プロレベルのデザイン知識ベース。全AI（Muse／ChatGPT／Mac Claude／将来のAI）共通の正本。
HP・チラシ・SNS・動画・ブログなど、あらゆる制作物はこのOSを参照して作る。

## 目的

- 制作物のデザイン品質を「担当AIの感覚」ではなく「蓄積されたルール」で担保する。
- 学習は毎日少しずつ行い、再現可能なルールとしてここへ蓄積する（感想は蓄積しない）。
- 制作したら事例として記録し、良し悪しを次のルールに還元する。

## 使い方（全AI共通）

1. 制作前に、媒体に合うモジュールを読む（下表）。
2. ブリーフ（目的・対象・媒体・サイズ・納期）を決めてから作る。目的が言えない制作物は作らない。
3. 制作後、07_QC_CHECKLISTS で自己点検してから提出・公開する。
4. 新しく学んだことは 09_LEARNING_SYSTEM の形式で LEARNING_LOG に追記し、2回観測されたら原則モジュールへ昇格させる（PRで反映）。

## モジュール一覧

| ファイル | 内容 | 主な利用場面 |
|---|---|---|
| 00_PRINCIPLES.md | 設計原則（全制作共通の憲法） | すべて |
| 01_COMPOSITION.md | 構図：視線誘導・余白・分割・階層 | すべて |
| 02_COLOR.md | カラー：配色比率・パレット・色の役割 | すべて |
| 03_TYPOGRAPHY.md | 文字：フォント階層・英字主役の型・行間 | すべて |
| 04_PHOTO_AND_IMAGE.md | 写真・画像：実写原則・グレーディング基準 | 写真を使う制作 |
| 05_MEDIA_LAYOUTS.md | 媒体別レイアウト仕様 | HP／チラシ／SNS／動画／ブログ |
| 06_PRODUCTION_WORKFLOW.md | 制作フローとAI分担 | 制作の進め方 |
| 07_QC_CHECKLISTS.md | 公開前チェックリスト | 提出・公開前 |
| 08_CASE_STUDIES.md | 事例集（成功・失敗と理由） | 参照・学習 |
| 09_LEARNING_SYSTEM.md | 毎日の学習ループの設計 | 学習タスク |
| LEARNING_LOG.md | 学習ログ（観測→解釈→ルール化） | 学習タスク |
| CHANGELOG.md | 版の履歴 | 管理 |

## 版管理

- 形式は Markdown のみ（どのAIでも読める）。
- 変更はブランチ→PR→マージ。マージは常時ルール（収益減・支出・問題リスクがある場合のみ事前確認）に従う。
- ルールを変えたら CHANGELOG に1行残す。ルールの削除より「改訂理由の明記」を優先する。
